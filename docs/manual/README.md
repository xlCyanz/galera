# Manual de Galera

Para quien **usa** Galera: hacer un documento, rellenarlo y sacarlo en PDF.
Quien quiera programarla tiene el [README](../../README.md) y
[CONTRIBUTING](../../CONTRIBUTING.md).

Galera es un editor de documentos en el que colocas las cosas sobre la página
con el ratón, como en una herramienta de diseño, pero lo que ves en el lienzo
lo compone **Typst**, el mismo motor que escribe el PDF. Lo que ves es lo que
sale: los saltos de línea, los tamaños y las posiciones no cambian al
exportar.

## Convenciones de este manual

- Los nombres **entre comillas** son los que se ven en la pantalla:
  «Exportar a…», la pestaña «Capas».
- Los atajos se escriben con las teclas de macOS (`⌘`, `⇧`, `⌥`). En
  Windows, `⌘` es `Ctrl` y `⌥` es `Alt`.
- Las medidas van en milímetros, como en la app.
